**Dashboard interativo para consulta e previsão do preço do boi gordo no Brasil.**

Projeto de Ciência de Dados que calcula o valor de animais por arroba, mostra a evolução do preço e faz previsão para os próximos 90 dias usando dados oficiais do Cepea/SP (referência nacional).

---

## ✨ Funcionalidades

- Calculadora de preço por peso vivo (boi, vaca e novilha)
- Estimativa automática de arrobas e valor total
- Previsão de preço da arroba para os próximos 90 dias (Prophet)
- Gráfico interativo com foco nos últimos 12 meses + previsão
- Comparação histórica com cotação do Dólar (USD/BRL)
- Interface limpa e responsiva (funciona bem no celular)

---

## 🛠️ Tecnologias Utilizadas

- **Python**
- **Streamlit** (dashboard)
- **Pandas** + **NumPy**
- **Prophet** (previsão de série temporal)
- **Plotly** (gráficos interativos)
- **yfinance** (cotação do dólar)
- **Cepea/ESALQ** (dados oficiais)
